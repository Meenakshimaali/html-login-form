# Login Form

A simple login form created using HTML and CSS.

## Features

- Email or phone input field
- Password input field
- Forgot password option
- Login button
- Signup link
- Gradient background
- Hover effect on login button
- Centered form layout

## Technologies Used

- HTML5
- CSS3

## Project Preview

A simple and clean login interface designed to practice HTML forms, input fields, CSS styling, gradients, and hover effects.
